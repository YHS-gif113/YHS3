# 竞赛证书智能识别与信息管理平台
 
## 系统概述
本系统是一个基于Streamlit框架开发的竞赛证书智能识别与信息管理平台，通过集成多种视觉识别API实现证书信息的自动提取，为学校或教育机构提供高效的证书信息采集和管理解决方案。
 
## 功能特点
- 三种用户角色：学生、教师、管理员
- 学（工）号格式验证和唯一性检查
  - 学生：13位数字学号
  - 教师：8位数字工号
  - 管理员：可通过批量导入创建
- 密码强度验证（至少8位，包含字母和数字）
- 用户批量导入功能（Excel格式）
- 基于角色的权限控制（RBAC）
- 证书文件上传和智能识别
- 信息核实与修改
- 数据导出功能
 
## 环境要求
- Python 3.8+
- VSCode 1.90+
- Chrome浏览器
 
# 安装步骤
1. 克隆项目到本地
2. 创建虚拟环境并激活
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate    # Windows
   ```
3. 安装依赖包
   ```bash
   pip install -r requirements.txt
   ```
4. 初始化数据库（自动创建）
   系统首次运行时会自动创建数据库和表结构

## 运行系统
```bash
streamlit run app.py
```
系统将在浏览器中自动打开，默认地址：http://localhost:8501

## 用户注册说明
### 学生注册
- 学（工）号：13位数字学号
- 角色类型：选择"学生"
- 必填信息：姓名、单位/学院、邮箱
- 密码要求：至少8位，包含字母和数字

### 教师注册
- 学（工）号：8位数字工号
- 角色类型：选择"教师"
- 必填信息：姓名、单位/学院、邮箱
- 密码要求：至少8位，包含字母和数字

### 管理员账号
管理员账号需要通过批量导入功能创建，不支持在线注册

## 批量导入功能
管理员可以通过Excel文件批量导入用户信息：

1. 准备Excel文件，包含以下列：
   - **学（工）号**（必填）：学生13位，教师8位
   - **姓名**（必填）
   - **角色类型**（必填）：学生/教师/管理员
   - **单位**（必填）
   - **邮箱**（必填）
   - **初始密码**（可选）：未填写则自动生成

2. 访问批量导入页面
3. 上传Excel文件
4. 查看导入结果和报告

### 模板文件
系统提供了示例文件：`sample_users.xlsx`，包含正确的格式和示例数据

### 导入报告
每次导入后，系统会生成详细报告：
- 成功导入的用户列表和初始密码
- 导入失败的记录和失败原因
- 重复记录（学工号已存在）

报告保存在 `import_test_report.md`

## 技术栈
- **Web框架**：Streamlit 1.28+
- **数据库**：SQLite + SQLModel
- **密码加密**：bcrypt
- **数据处理**：Pandas
- **Excel处理**：openpyxl

## 权限说明
### 学生权限
- 上传个人证书
- 提取证书信息
- 核实和提交数据

### 教师权限
- 上传学生证书
- 提取证书信息
- 核实和提交数据

### 管理员权限
- 用户管理
- 批量导入用户
- 数据查看和导出
- 系统配置

## 注意事项
1. 密码必须至少8位，包含字母和数字
2. 学（工）号和邮箱必须唯一
3. 学生学号必须是13位数字
4. 教师工号必须是8位数字
5. 批量导入时，如遇到重复学工号，系统会跳过该记录
6. 建议首次登录后修改初始密码

## 问题排查
如果遇到问题，请检查：
1. Python版本是否为3.8及以上
2. 所有依赖包是否正确安装
3. 数据库文件是否有读写权限
4. Excel文件格式是否正确
